КАК УСТРОЕН FABRIRIO
Ваш код — производственная линия.
Функции становятся цехами, операции — станками, значения — грузами на конвейерах. Нажмите на объект, чтобы увидеть его исходный код и связи.
◈ Типы и цвета
Форма груза и вагона обозначает семейство типа Go, цвет — конкретный тип. Лента и мост окрашены в цвета перевозимых грузов; общие ленты полосатые. Легенда показывает типы текущей линии.
▧ Цвет блока
Один вызываемый метод — один цвет корпуса и фундамента. Другие операции получают цвет своей функции; он сохраняется при смене участка и масштаба.
▰ Конвейер
Зависимость между значениями SSA. Стрелки по всей ленте и мостам показывают направление даже на паузе. Пересечения проходят через мосты.
↻ Раскладка
Связанные объекты притягиваются друг к другу. Чем больше соседей у объекта, тем ближе он к центру своей группы. «Перестроить по связям» применяет новую раскладку к текущему виду, включая сохранённую фабрику.
⌒ Мост
Поднятая лента с въездами. Мосты не пересекаются между собой.
▣ Склад
Запись в SQL, GORM, MongoDB, Redis
↑ Ракета
Отправка HTTP, gRPC, WebRTC, WebSocket
═ Поезд
Состав с локомотивом и вагонами на рельсах между концами Go-канала.
▥ Мусорка
Один тайл: конец использования значения или delete.
Это статическая модель: движение грузов иллюстративно. Ветви, циклы и несколько вызывающих функций показывают возможные пути. Освобождение памяти и реальные значения без запуска программы не наблюдаются.
Для собственных обёрток добавьте перед функцией //fabririo:rocket grpc или //fabririo:warehouse postgres.
Границы анализа
    Перетаскивайте блоки левой кнопкой: координаты привязываются к сетке, маршруты перестраиваются после отпускания. Пустое место, Shift + перетаскивание или средняя кнопка двигают карту. Esc отменяет перенос. Изменения автоматически сохраняются в этом браузере; «Экспорт → JSON» и «Импорт JSON» переносят фабрику между компьютерами.

    Стандартные пресеты — точный кадр 16:9. Текущий вид вписывается целиком с полями, без растягивания; компактные размеры — по длинной стороне. GIF повторяется по кругу и сохраняет текущую скорость, цвета и подсветку. Движение записывается даже при паузе на карте. Экспортируется открытый участок, без панелей интерфейса.
    
      
    
      
    
        
        
        
    Один файл UTF-8: строки node — объекты, edge — связи. Включены типы, цвета и исходники; для построенной фабрики — координаты, ленты, рельсы и мосты. Полный граф содержит все операции, в том числе скрытые; без раскладки.
    
      
    
      
    Снимок для восстановления через «Импорт JSON»: полный граф, исходники, раскладки всех посещённых цехов и участков, камера, фильтры и анимация. Файл включает содержимое исходников. Старый JSON графа также можно импортировать — с автоматической раскладкой.
